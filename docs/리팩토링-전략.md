## 맥락

레거시 코드를 안전하게 리팩토링하기 위해 단계적 접근 전략이 필요했다.
작동을 바꾸기 쉬운 상태를 만드는 것이 목표이며, 구조 변경을 통해 변경 난이도를 낮추되 작동은 유지한다.

## 결정

4단계 접근법을 채택한다:

1. **코드 분석** — 현재 상태 파악
2. **인수 테스트 작성** — 안전망 확보
3. **서비스 계층 추출** — 구조 변경, 작동 변경 없음
4. **코드 스멜 수정** — 품질 개선

핵심 원칙:
- 구조 변경과 작동 변경을 섞지 않는다
- 한 커밋에는 목적 1개만 담는다
- 각 단위별로 테스트 실행 후 커밋한다
