# 용어 사전 (Glossary)

이 프로젝트에서 쓰는 핵심 용어와 그 뜻을 정리한 문서다. 문서와 대화에서는 아래 한글명을, 코드와 API에서는 영문명을 기준으로 쓴다.

| 한글명 | 영문명 | 설명 |
|---|---|---|
| 회원 | member | 이 서비스에 계정이 있는 사람. 이메일로 회원 가입을 했거나 카카오 로그인으로 계정이 생긴 사람이다. 로그인 토큰이 있어야 위시와 주문을 쓸 수 있다. |
| 비회원 | guest | 로그인하지 않은 사람. 상품, 카테고리, 옵션을 둘러볼 수 있다. |
| 관리자 | admin | 관리자 화면에서 상품과 회원을 관리하는 사람. 지금은 관리자인지 확인하는 장치가 없어서, 로그인하지 않아도 누구나 관리자 화면을 쓸 수 있다. 초기 데이터의 admin 계정도 다른 회원과 똑같은 일반 회원이다. |
| 상품 | product | 판매하는 물건. 카테고리 하나에 속하고, 옵션을 하나 이상 가진다. |
| 상품명 | product name | 상품의 이름. 공백을 포함해 15자까지 쓸 수 있고, 특수 문자는 정해진 몇 가지만 쓸 수 있다. "카카오"가 들어간 이름은 담당 MD와 협의한 경우에만 쓸 수 있어서, 관리자 화면에서만 등록할 수 있다. |
| 가격 | price | 상품 1개의 가격. 옵션마다 가격이 따로 있지 않고, 같은 상품의 옵션은 모두 같은 가격이다. |
| 카테고리 | category | 상품을 묶는 분류. 예: 전자기기, 패션, 식품. 이름, 색, 이미지, 설명을 가진다. |
| 옵션 | option | 같은 상품 안에서 고르는 세부 선택지. 예: 색상과 사양, 사이즈. 옵션마다 재고가 따로 있다. 상품마다 옵션이 최소 1개는 있어야 해서, 하나 남은 옵션은 삭제할 수 없다. 주문할 때는 상품이 아니라 옵션을 고른다. |
| 옵션명 | option name | 옵션의 이름. 공백을 포함해 50자까지 쓸 수 있고, 같은 상품 안에서 같은 옵션명을 두 번 쓸 수 없다. |
| 재고 | stock | 옵션별로 남아 있는 수량. 주문하면 주문 수량만큼 줄어든다. 재고보다 많이 주문할 수는 없다. |
| 주문 수량 | order quantity | 한 번 주문할 때 사는 개수. 1개 이상이어야 한다. 남아 있는 수량인 재고와는 다른 말이다. |
| 주문 | order | 회원이 옵션을 골라 포인트로 사는 것. 주문 수량, 주문 메시지, 주문한 시각이 함께 기록된다. 회원은 자기 주문 내역을 볼 수 있다. |
| 주문 금액 | total price | 한 번 주문할 때 내는 돈. 상품 가격에 주문 수량을 곱한 값이고, 이만큼 포인트가 차감된다. |
| 주문 메시지 | order message | 주문할 때 함께 남기는 짧은 글. 쓰지 않아도 된다. 주문 알림에 함께 담긴다. |
| 선물 | gift | 이 서비스가 주문을 부르는 방식. 주문 알림 문구와 주문 메시지는 누군가에게 선물을 보내는 상황을 전제로 한다. 하지만 받는 사람을 고르는 기능은 없다. |
| 위시 | wish | 회원이 관심 있는 상품을 담아 두는 목록. 같은 상품은 한 번만 담긴다. 자기 위시만 삭제할 수 있다. |
| 포인트 | point | 회원이 주문할 때 돈 대신 쓰는 금액. 관리자가 충전해 준다. 회원이 자기 포인트를 직접 확인하는 기능은 없고, 관리자 화면에서만 보인다. |
| 포인트 충전 | charge point | 관리자가 회원의 포인트를 늘려 주는 것. 1 이상의 금액만 충전할 수 있다. |
| 차감 | deduct | 주문할 때 포인트와 재고를 줄이는 것. 포인트는 주문 금액만큼, 재고는 주문 수량만큼 줄어든다. |
| 로그인 토큰 | login token | 회원 가입, 로그인, 카카오 로그인을 하면 이 서비스가 내주는 확인증. 위시나 주문을 쓸 때 함께 보내면 서비스가 어느 회원인지 알아본다. 카카오 액세스 토큰과는 다르다. 로그인 토큰은 이 서비스가 만들어 회원에게 주는 것이고, 카카오 액세스 토큰은 카카오가 만들어 이 서비스가 보관하는 것이다. |
| 카카오 액세스 토큰 | Kakao access token | 카카오 로그인을 할 때 카카오가 내주는 확인증. 이 서비스가 보관해 두었다가, 회원에게 카카오톡으로 주문 알림을 보낼 때 쓴다. 회원이 직접 다루지 않으며, 로그인 토큰과는 다르다. |
| 회원 가입 | register | 사람이 스스로 이메일과 비밀번호를 넣어 계정을 만드는 것. 가입하면 바로 로그인 토큰을 받는다. 카카오 로그인을 처음 하면 회원 가입도 자동으로 된다. |
| 등록 | create | 상품, 카테고리, 옵션을 새로 만드는 것. 관리자가 관리자 화면에서 회원 계정을 만드는 것도 등록이라고 한다. 사람이 스스로 계정을 만드는 것은 등록이 아니라 회원 가입이라고 부른다. |
| 카카오 로그인 | Kakao login | 카카오 계정으로 이 서비스에 로그인하는 것. 카카오에서 동의하면 로그인 토큰을 받는다. 처음이면 회원 가입이 자동으로 된다. 카카오 로그인을 한 회원만 주문 알림을 받을 수 있다. |
| 주문 알림 | order notification | 주문한 뒤 카카오톡으로 가는 메시지. 상품명, 옵션명, 주문 수량, 주문 금액, 주문 메시지가 담긴다. 문구는 선물이 도착했다고 하지만 주문한 본인에게 간다. 보내기에 실패해도 주문은 그대로 성공한다. |
| 이미지 URL | image URL | 상품이나 카테고리의 이미지가 있는 인터넷 주소. |
