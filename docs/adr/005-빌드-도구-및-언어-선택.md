# ADR 005: 빌드 도구 및 언어 선택

> 작성일: 2026-03-05
> 상태: Accepted

## Context (맥락)

프로젝트의 빌드 도구와 주요 개발 언어를 결정해야 했다. Spring Boot 프로젝트로서 Maven과 Gradle 중 빌드 도구를 선택하고, Java와 Kotlin 중 주 개발 언어를 결정해야 했다.

## Decision (결정)

빌드 도구로 Gradle(Kotlin DSL)을 사용한다. 주 소스 코드는 Java로 작성하되, 빌드 스크립트는 Kotlin DSL(build.gradle.kts)을 사용한다. Java 21을 타겟으로 하며, ktlint를 통해 Kotlin 코드 스타일을 관리한다. Spring Boot 3.5.x 기반이다.

## Consequences (결과)

### Pros
- Gradle의 빠른 빌드 속도와 유연한 설정이 가능하다
- Kotlin DSL로 빌드 스크립트의 타입 안전성과 IDE 지원이 향상된다
- Java 21의 최신 기능(record, sealed class 등)을 활용할 수 있다

### Cons
- Gradle Kotlin DSL은 Groovy DSL 대비 학습 곡선이 있다
- Java와 Kotlin이 혼용되어 빌드 설정에서 양쪽 플러그인 관리가 필요하다
