# ADR 003: 데이터베이스 및 마이그레이션 전략

> 작성일: 2026-03-05
> 상태: Accepted

## Context (맥락)

프로젝트의 데이터 영속성을 위한 데이터베이스와, 스키마 변경을 관리하기 위한 마이그레이션 전략이 필요했다. 개발 환경과 운영 환경에서 각각 다른 데이터베이스를 사용할 수 있어야 했다.

## Decision (결정)

운영 환경에서는 MySQL을, 개발/테스트 환경에서는 H2 인메모리 데이터베이스를 사용한다. 스키마 마이그레이션은 Flyway를 사용하여 버전 관리한다. ORM은 Spring Data JPA를 사용한다.

## Consequences (결과)

### Pros
- Flyway를 통해 스키마 변경 이력이 코드로 관리되어 추적이 용이하다
- H2를 통한 빠른 테스트 실행이 가능하다
- Spring Data JPA로 반복적인 CRUD 코드를 줄일 수 있다

### Cons
- H2와 MySQL 간 SQL 방언 차이로 인한 테스트 불일치 가능성이 있다
- Flyway 마이그레이션 스크립트를 MySQL과 H2 모두 호환되도록 작성해야 한다
