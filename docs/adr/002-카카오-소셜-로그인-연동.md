# ADR 002: 카카오 소셜 로그인 연동

> 작성일: 2026-03-05
> 상태: Accepted

## Context (맥락)

사용자 회원가입 및 로그인 기능이 필요했다. Spring Security OAuth2 Client를 사용하는 방식과 RestClient를 이용한 직접 구현 방식을 고려했다. 카카오 OAuth2 인증 코드 방식을 통해 사용자 이메일을 획득하고, 자체 JWT를 발급하는 흐름이 필요했다.

## Decision (결정)

Spring Security를 사용하지 않고, RestClient를 이용하여 카카오 OAuth2 API를 직접 호출하는 방식을 채택한다. KakaoLoginClient가 인증 코드로 액세스 토큰을 요청하고, 해당 토큰으로 사용자 정보를 조회한다. 획득한 이메일로 자체 회원 등록 및 JWT 토큰을 발급한다.

## Consequences (결과)

### Pros
- Spring Security 의존성 없이 경량화된 구현이 가능하다
- 인증 흐름을 명시적으로 제어할 수 있어 디버깅이 용이하다
- 카카오 API 연동 로직이 KakaoLoginClient에 캡슐화되어 있다

### Cons
- Spring Security가 제공하는 보안 기능(CSRF, 세션 관리 등)을 직접 구현해야 한다
- 다른 소셜 로그인 제공자 추가 시 각각 클라이언트를 구현해야 한다
