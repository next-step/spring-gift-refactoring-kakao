# ADR-002: 주문 시 위시 자동 정리 전략

## 상태
채택됨

## 맥락
주문 흐름에서 "위시 정리" 단계가 누락되어 있었다.
사용자가 위시리스트에 담은 상품을 주문하면, 해당 위시를 자동으로 제거해야 한다.

구현 방식으로 두 가지 선택지가 있었다:
1. **트랜잭션 내 동기 처리**: `placeOrder()` 트랜잭션 안에서 `WishService.removeByMemberAndProduct()` 호출
2. **이벤트 기반 비동기 처리**: `@TransactionalEventListener`로 주문 완료 이벤트 발행 후 별도 트랜잭션에서 위시 삭제

## 결정
**트랜잭션 내 동기 처리**를 채택한다.

## 근거
- 위시 삭제는 주문의 부수 효과이므로, 주문 실패 시 위시가 남아 있어야 자연스럽다 (트랜잭션 원자성)
- 위시가 없는 상품을 주문해도 `findByMemberIdAndProductId`가 빈 Optional을 반환하여 no-op
- 현재 규모에서 이벤트 기반 비동기 처리는 복잡도 대비 이점이 없다
- 향후 성능 이슈 발생 시 이벤트 기반으로 전환 가능 (인터페이스 변경 없음)

## 영향
- `OrderService`가 `WishService`에 새로운 의존성을 갖게 됨
- 주문 트랜잭션에 위시 조회/삭제 쿼리가 1~2개 추가됨
- 위시가 없는 경우 SELECT 1회 추가 (무시할 수준)
