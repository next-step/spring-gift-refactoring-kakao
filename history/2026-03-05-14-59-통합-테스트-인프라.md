# 통합 테스트 인프라 구축 계획

> 작성일: 2026-03-05 14:59

## 배경

ADR 006에서 서비스 레이어 트랜잭션 경계를 재정립했으나, 모든 테스트가 Mockito 기반 단위 테스트여서 트랜잭션 롤백, 이벤트 리스너 동작 등 실제 Spring 컨텍스트에서만 검증 가능한 동작을 확인할 수 없다. `application-test.properties`(H2)가 존재하지만 사용하는 테스트가 없는 상태이다.

## 계획 내용

### 구조 변경 (신규 파일 7개, 기존 파일 수정 없음)

- `@IntegrationTest` 커스텀 어노테이션 추가 예정 (`@SpringBootTest` + `@ActiveProfiles("test")` + `@Transactional`)
- `@IntegrationTestWithoutTx` 커스텀 어노테이션 추가 예정 (이벤트 리스너/실제 롤백 검증용, `@Transactional` 없음)
- `IntegrationTestFixtures` 추가 예정 (Repository를 받아 실제 DB에 저장하는 픽스처 헬퍼)

### 작동 변경

- `OrderServiceIntegrationTest`: placeOrder 정상 흐름(재고 감소, 포인트 차감, 주문 저장), **포인트 부족 시 option 재고 롤백**, 재고 부족 시 포인트 미차감을 실제 DB에서 검증
- `OrderEventListenerIntegrationTest`: 커밋 후 카카오 메시지 이벤트 리스너 호출 확인, 롤백 시 미호출 확인, kakaoToken null 시 미호출 확인
- `MemberServiceIntegrationTest`: `findOrCreateByEmailAndUpdateKakaoToken`의 신규 회원 생성 및 기존 회원 토큰 업데이트를 실제 DB에서 검증
- ADR 007 문서 작성 예정 (테스트 분류 기준, 어노테이션 전략, 외부 의존성 mock 전략)

### 설계 결정

- 트랜잭션 롤백 검증 테스트는 `@IntegrationTestWithoutTx`를 사용 — 테스트의 `@Transactional`이 서비스 트랜잭션을 감싸면 실제 롤백이 발생하지 않기 때문
- 외부 API 클라이언트(`KakaoMessageClient`)는 `@MockBean`으로 대체

## 주요 파일 (예정)

- `src/test/java/gift/IntegrationTest.java` - 커스텀 통합 테스트 어노테이션 (Tx)
- `src/test/java/gift/IntegrationTestWithoutTx.java` - 커스텀 통합 테스트 어노테이션 (No Tx)
- `src/test/java/gift/IntegrationTestFixtures.java` - DB 저장 픽스처 헬퍼
