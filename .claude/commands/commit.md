allowed-tools: Bash

아래 명령어를 실행하고 결과를 분석한다.
```bash
git log -n 10 --oneline && echo "---" && git diff --cached --stat
```

`--cached`가 비어 있으면 `git diff --stat`도 실행한다.

히스토리에서 아래 패턴을 파악한다.

- 접두어: `feat:`, `fix:`, `[FIX]`, `FEAT -` 등
- 이모지 사용 여부 및 위치
- 언어: 한글 / 영어 / 혼용
- 한글 종결 어미: 명령문(`추가`), `~함`, `~기`, `~했습니다`
- 영어 동사형: 명령형(`Add`), 과거형(`Added`)
- 대소문자 규칙
- 티켓/이슈 번호 포함 여부

출력 형식:

**추천 커밋 메시지:**
```
<분석한 스타일을 완벽히 복제한 메시지>
```

**추천 이유:**
기존 히스토리의 [파악한 특정 패턴]을 그대로 반영함.

패턴이 혼재할 경우 빈도 높은 패턴 기준으로 선택하고 이유를 한 줄로 명시한다. 대안은 필요한 경우에만 제시한다.
